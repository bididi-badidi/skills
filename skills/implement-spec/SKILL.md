# Implement Spec

Use this skill when tasked with turning a specification, RFC, or requirements document into working code.

## Objectives

1. Understand the specification thoroughly before writing code.
2. Identify dependencies, affected components, and public interfaces.
3. Implement features incrementally with test coverage.
4. Verify complete conformance against acceptance criteria.

## Procedure

### 1. Review specification

- Extract core requirements, edge cases, and interfaces.
- Confirm any ambiguous points before making assumptions.

### 2. Formulate implementation plan

- Break implementation into logically ordered milestones.
- Specify tests for each requirement.

### 3. Implement and test

- Write unit/integration tests covering the spec requirements.
- Implement code changes to satisfy tests.

### 4. Conformance verification

- Validate all acceptance criteria from the spec.
- Run complete test suite and linters.

## Constraints

- Do not deviate from the specification without explicit justification.
- Do not bypass test validation.
