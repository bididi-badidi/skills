# Example Skill

Use this skill as a template when adding new skills to the repository.

## Objectives

1. Demonstrate standard SKILL.md structure.
2. Show how supporting references can be integrated.
3. Validate against repository skill requirements.

## Procedure

### 1. Define triggers and scope

Identify clear conditions for when the skill should activate.

### 2. Follow established standards

- Use lowercase kebab-case directory names.
- Provide frontmatter with `name` and `description`.
- Document objectives, procedures, and constraints.

### 3. Provide supporting materials if needed

Add references or scripts under `references/` or `scripts/` if additional context is required.

## Constraints

- Only add supporting directories when genuinely needed.
- Keep instructions focused, practical, and clear.
